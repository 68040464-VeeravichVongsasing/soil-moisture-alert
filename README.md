# 🌱 ระบบแจ้งเตือนความชื้นและรดน้ำอัตโนมัติ (Smart Farm Alert)

โครงการซอฟต์แวร์ต้นแบบ (Prototype) สำหรับช่วยเหลือเกษตรกรรายย่อยในการติดตามค่าความชื้นในดินและควบคุมการให้น้ำพืชสวนผ่านสมาร์ทโฟนแบบเรียลไทม์ ลดภาระการเดินตรวจแปลงและเพิ่มความแม่นยำในการบริหารจัดการน้ำ พัฒนาด้วยภาษา Python และ Streamlit

🚀 **ทดลองใช้งานระบบ (Live Demo):** [https://kmitl-soil-alert.streamlit.app/](https://kmitl-soil-alert.streamlit.app/)

## ✨ ฟีเจอร์หลัก (Key Features)

1. **FR-01: Modern UI & Live Dashboard:** แสดงค่าความชื้นในดินปัจจุบัน พร้อมสถานะปั๊มน้ำแบบ Real-time บนส่วนติดต่อผู้ใช้รูปแบบ Hero Card ที่ทันสมัย สบายตา และรองรับการแสดงผลบนสมาร์ทโฟน (Responsive)
2. **FR-02: Smart Alert System:** ระบบแจ้งเตือนอัตโนมัติ พร้อมเปลี่ยนสีกรอบแสดงสถานะ (เขียว/แดง) ทันทีเมื่อความชื้นต่ำกว่าเกณฑ์ที่กำหนด
3. **FR-03: Real-time Auto Watering:** โหมดรดน้ำอัตโนมัติ (Auto Mode) ที่ตอบสนองทันทีเมื่อปรับเกณฑ์ มาพร้อม **แอนิเมชันจำลองการรดน้ำ** (ตัวเลขความชื้นและกราฟไต่ระดับขึ้นแบบเรียลไทม์) และตัดการทำงานเองเมื่อความชื้นถึง 90% เพื่อป้องกันน้ำท่วมขัง
4. **FR-04: Manual Control & Emergency Stop:** โหมดควบคุมด้วยตนเอง (Manual Mode) และระบบปุ่ม "ปิดฉุกเฉิน" (Emergency Stop) ในระหว่างที่โหมด Auto กำลังทำงาน เพื่อความปลอดภัยสูงสุด
5. **FR-05: Data History Chart:** กราฟแสดงประวัติความชื้นย้อนหลังดึงข้อมูลจากฐานข้อมูล SQLite โดยตรง แสดงการเปลี่ยนแปลงของความชื้นแบบละเอียด 
6. **Code Quality:** ผ่านการทดสอบด้วย Unit Test (`pytest`) 100%

## ⚙️ วิธีติดตั้งและรันบนเครื่อง (Local Setup)

เปิด Terminal ใน VS Code แล้วรันชุดคำสั่งด้านล่างนี้ตามลำดับ:

```bash
# 1. โคลนโปรเจกต์ลงเครื่อง
git clone https://github.com/68040464-VeeravichVongsasing/-.git
cd [ชื่อโฟลเดอร์โปรเจกต์]

# 2. สร้างและเปิดใช้งาน Virtual Environment
python -m venv .venv
# สำหรับ Windows:
.venv\Scripts\activate
# สำหรับ Mac/Linux:
# source .venv/bin/activate

# 3. ติดตั้งแพ็กเกจที่จำเป็น
pip install -r requirements.txt

# 4. เปิดใช้งานแอปพลิเคชัน Streamlit
streamlit run app.py
```

## 📚 แหล่งข้อมูลและอ้างอิง

* **สถิติภูมิอากาศรายวัน:** แหล่งข้อมูลเปิด (data.go.th)
* **ข้อมูลอุณหภูมิและปริมาณน้ำฝน:** กรมอุตุนิยมวิทยา (TMD)
* **อัตราการระเหยน้ำ (Evapotranspiration):** อ้างอิงจากกรมวิชาการเกษตร/กรมส่งเสริมการเกษตร (อัตราการระเหยไม้ผลเฉลี่ย 3.8-5.7 มม./วัน) นำมาประยุกต์ใช้ในการจำลองสภาพแวดล้อม
