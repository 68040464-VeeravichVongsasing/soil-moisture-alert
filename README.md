# ระบบแจ้งเตือนความชื้นและรดน้ำอัตโนมัติ (Smart Farm Prototype)

โครงการซอฟต์แวร์ต้นแบบสำหรับช่วยเหลือเกษตรกรรายย่อยในการติดตามค่าความชื้นในดินและควบคุมการให้น้ำพืชสวนผ่านสมาร์ทโฟนแบบเรียลไทม์ ลดภาระการเดินตรวจแปลงและเพิ่มความแม่นยำในการบริหารจัดการน้ำ

## ✨ ฟีเจอร์หลัก (MVP Features)
1. **FR-01:** แสดงค่าความชื้นในดินปัจจุบัน พร้อมสถานะปั๊มน้ำแบบ Real-time (`st.metric`)
2. **FR-02:** ระบบแจ้งเตือนอัตโนมัติ (`st.error` / `st.success`) เมื่อความชื้นต่ำกว่าเกณฑ์ที่กำหนด
3. **FR-03 & FR-04:** แผงควบคุมระบบ (Control Panel) รองรับทั้งโหมดอัตโนมัติ (Auto Mode) และเปิด-ปิดด้วยตนเอง (Manual Mode)
4. **FR-05:** กราฟแสดงประวัติความชื้นย้อนหลัง (`st.line_chart`) จากฐานข้อมูล SQLite
5. **Testing:** ผ่านการทดสอบด้วย Unit Test (`pytest`) ความถูกต้อง 100%

## ⚙️ วิธีติดตั้งและรันบนเครื่อง (Local Setup)

เปิด Terminal ใน VS Code แล้วรันชุดคำสั่งด้านล่างนี้ตามลำดับ:

```bash
# 1. โคลนโปรเจกต์ลงเครื่อง (หรือเปิดโฟลเดอร์โปรเจกต์ที่มีอยู่)
git clone https://github.com/68040464-VeeravichVongsasing/-.git
cd [ชื่อโฟลเดอร์โปรเจกต์]

# 2. สร้างและเปิดใช้งาน Virtual Environment
python -m venv .venv
# สำหรับ Windows:
.venv\Scripts\activate
# สำหรับ Mac/Linux:
# source .venv/bin/activate

# 3. ติดตั้งแพ็กเกจที่จำเป็น
pip install -r requirements.txt

# 4. เปิดใช้งานแอปพลิเคชัน Streamlit
streamlit run app.py
```

## 📚 แหล่งข้อมูลและอ้างอิง
- **สถิติภูมิอากาศรายวัน:** แหล่งข้อมูลเปิด (data.go.th)
- **ข้อมูลอุณหภูมิและปริมาณน้ำฝน:** กรมอุตุนิยมวิทยา (TMD)
