# ร่างเนื้อหาสำหรับแบบฟอร์ม CCS (ข้อ 8 ประโยชน์ที่คาดว่าจะได้รับ)

8.1 ได้ต้นแบบระบบแจ้งเตือนความชื้นและรดน้ำอัตโนมัติ (Software Prototype) ที่สามารถนำไปประยุกต์ใช้งานและเชื่อมต่อกับฮาร์ดแวร์ IoT ได้จริงในอนาคต
8.2 ช่วยลดความกังวล ลดภาระงาน และลดระยะเวลาของเกษตรกรในการเฝ้าระวังความชื้นในดิน โดยสามารถติดตามผ่านสมาร์ทโฟนได้ทุกที่
8.3 สร้างความเข้าใจและการบูรณาการความรู้ระหว่างการเขียนโปรแกรม (Python) และข้อมูลด้านการเกษตร (อัตราการระเหยน้ำ) เพื่อแก้ปัญหาจริง
8.4 [อิงจากผลประเมิน] เกษตรกรกลุ่มตัวอย่างมีความพึงพอใจต่อระบบในระดับ [รอใส่ค่าประเมิน] ซึ่งสะท้อนให้เห็นถึงความง่ายในการใช้งาน (Usability) ของแอปพลิเคชัน
